# 🌦️ Weather App

A responsive Weather Application built using HTML, CSS, and JavaScript. It fetches weather information for a searched city using the Open-Meteo APIs.

## ✨ Features

* Search weather by city name
* Display temperature in Celsius
* Show feels-like temperature
* Display humidity and wind speed
* Show weather conditions with emojis
* Loading status while fetching data
* Error handling for failed API requests
* Responsive design for mobile and desktop screens

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Open-Meteo Geocoding API
* Open-Meteo Weather Forecast API
* Font Awesome Icons

## 🌐 APIs Used

**1. Geocoding API**
Used to retrieve city coordinates and country information.

**2. Weather Forecast API**
Used to retrieve current temperature, feels-like temperature, humidity, wind speed, and weather codes.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Enter a city name and click **Search**.
